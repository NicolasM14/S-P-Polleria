# Glosario

## Objetivo

Definiciones **unívocas** de términos usados en S&F Pollería y en este sistema.

## Términos de negocio

| Término | Definición |
|---------|------------|
| **Producto** | Ítem vendible o componible: simple (kg/unidad) o combo |
| **Producto simple** | Tiene stock propio; unidad kg o unidad |
| **Combo** | Producto vendible sin stock propio; definido por receta de componentes |
| **Receta** | Lista de componentes y cantidades que forman un combo |
| **Stock** | Cantidad disponible de un producto simple |
| **Saldo** | Valor actual de stock para un producto |
| **Movimiento** | Registro inmutable que explica un cambio de stock |
| **Ajuste** | Movimiento manual de corrección de inventario |
| **Compra** | Ingreso de mercadería desde proveedor |
| **Venta** | Salida de mercadería por operación de mostrador |
| **Anulación** | Reversión de una venta; no borra el registro original |
| **Caja** | Control del efectivo físico del local |
| **Sesión de caja** | Período entre apertura y cierre |
| **Apertura** | Inicio de sesión con monto inicial en efectivo |
| **Cierre** | Fin de sesión con arqueo (contado vs esperado) |
| **Efectivo esperado** | Saldo teórico según movimientos en efectivo |
| **Diferencia** | Contado − esperado en cierre |
| **Gasto** | Egreso operativo (servicios, insumos no mercadería, etc.) |
| **Pago múltiple** | Una operación pagada con más de un método |
| **Método de pago** | Efectivo, transferencia, tarjeta, etc. |
| **Dueño** | Usuario con rol owner; acceso completo actual |
| **Empleado** | Rol futuro con permisos limitados configurables |

## Unidades

| Término | Definición |
|---------|------------|
| **Kg** | Kilogramo; cantidades con hasta **3 decimales** |
| **Unidad** | Pieza entera contable (ej. gaseosa, bolsa) |

## Términos excluidos (fuera de alcance)

| Término | Nota |
|---------|------|
| Cliente | No se gestionan clientes |
| Pedido WhatsApp | No integrado |
| Repartidor | No integrado |
| Factura electrónica | No ARCA/AFIP |
| Sucursal | Una sola locación |
